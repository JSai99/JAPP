# JAPP PDF 工作室 📄

自己動手做的免費 PDF 工具——不必買 Adobe，也不必把檔案上傳到來路不明的網站。

**所有處理都在你的瀏覽器裡完成，檔案完全不會離開你的電腦**，成績單、公文、考卷都可以放心編輯。

## 功能

- 📖 **閱讀**：開啟 PDF、縮圖側欄、翻頁、縮放、適寬顯示
- 🅣 **文字註記**：在任何位置加上文字（完整支援中文），可調字級與顏色
- 🖊️ **螢光筆**：拖曳標示重點
- ⬜ **修正帶**：白色色塊蓋住要修掉的內容
- ➕ **新增空白頁** / 🗑️ **刪除頁面**（可勾選多頁一次刪）
- 🔄 **旋轉頁面**、**拖曳縮圖調整頁面順序**
- 📥 **合併 PDF**：把另一個 PDF 的頁面加進來
- ↩︎ 復原（Ctrl+Z）、💾 儲存成新的 PDF 檔

## 使用方式

1. 下載整個專案（GitHub 頁面 → `Code` → `Download ZIP`，解壓縮）
2. 雙擊 `index.html`，用 Chrome 或 Edge 打開
3. 把 PDF 拖進視窗就可以開始用了

不需要安裝任何軟體、不需要網路連線（打開後離線也能用）。

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `←` / `→` | 上一頁 / 下一頁 |
| `Ctrl+Z` | 復原 |
| `Ctrl+S` | 儲存 PDF |
| `Delete` | 刪除選取的註記 |
| 雙擊文字註記 | 重新編輯文字 |

### 小提醒

- 已拖進文件的 PDF 若還有另一個要合併，直接把第二個檔案拖進視窗即可（會加在最後，再用縮圖拖曳排序）。
- 「儲存 PDF」會下載一個 `原檔名-編輯版.pdf`，原始檔案不會被更動。
- 有密碼保護的 PDF 需先解除密碼才能開啟。

## 技術架構

純靜態網頁，零後端、零建置流程：

| 元件 | 用途 | 授權 |
|---|---|---|
| [pdf.js](https://mozilla.github.io/pdf.js/)（Mozilla） | PDF 顯示與渲染 | Apache-2.0 |
| [pdf-lib](https://pdf-lib.js.org/) | PDF 頁面操作與匯出 | MIT |

兩個函式庫都直接放在 `vendor/`，所以學校網路就算擋 CDN 也照常運作。

中文文字註記的做法：由瀏覽器負責中文字型排版，匯出時轉成高解析度透明 PNG 嵌入 PDF——不必在 PDF 內嵌幾 MB 的中文字型檔。

```
index.html      介面
css/style.css   樣式
js/app.js       全部邏輯（載入、檢視、註記、頁面操作、匯出）
vendor/         pdf.js 與 pdf-lib（已下載，離線可用）
```
