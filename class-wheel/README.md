# JAPP 課堂轉盤 🎡

上課隨機抽人提問、隨機分組的小工具，設計給**投影在教室大螢幕**使用。

**學生名單只存在你這台電腦的瀏覽器裡，不會上傳到任何地方**，可以放心貼上全班名字。

## 功能

### 🎯 抽人（兩種儀式感）

- 🎡 **轉盤**：經典轉盤，指針撥過每一格都有「喀喀」聲，越轉越慢，停下時閃爍揭曉
- 🎰 **拉霸**：復古拉霸機，拉桿、跑馬燈、滾輪最後還會微微回彈
- **懸疑時間**可選短（約 4 秒）、中（約 7 秒）、長（約 11 秒）
- 抽中後全螢幕大字揭曉＋音效＋彩帶，**由老師決定**要「移除（這輪不再抽到）」或「保留在名單中」
- 抽過的人會記住（重新整理也不會不見），按「↺ 全部放回」再來一輪
- 側欄點學生名字可標記**缺席**（只在今天有效），缺席的人不會被抽到
- 「本堂紀錄」列出今天抽過誰

### 👥 分組

- 分組方式：**分成 N 組**，或**每組最多 M 人**（即時預覽「25 人分成 5 組，每組 5 人」）
- 平均分配依據：不限／**性別平均**／**系級平均**／**性別＋系級都平均**
- 可勾選**每組抽一位組長** 👑
- 揭曉動畫：小鼓滾奏洗牌，名字一個個飛進各組，每組有自己的音高；最後組長戴上皇冠、全場彩帶
- 揭曉速度：慢／中／快／立即
- 結果可**複製文字**（貼到 LINE、Moodle）或**下載 CSV**（Excel 開啟不會亂碼）

### 📋 名單管理

- 可以存**多個班級**，上方下拉選單切換
- 直接從 **Excel 複製欄位貼上**，**欄位順序不拘**：「班級、姓名」「學號、班級、姓名、性別」「姓名、性別、系級」都可以
  - 有標題列（姓名／性別／系級／班級）就照標題對應；沒有標題列時，會**看內容自動判斷**哪一欄是姓名（幾乎不重複）、哪一欄是系級（像「資四A」「財精二B」「社延B」）、哪一欄是性別或學號
  - 「辛　薇」這種補空白對齊的姓名會自動去掉空白；用空白隔開的「資四A 黃渝尹」也會自動分開
  - 舊版本曾把「班級、姓名」貼反（姓名變成小字），開啟新版時會自動修正
- 也可以匯入 Excel 另存的 `.csv`／`.txt`（UTF-8 或 Big5 都讀得懂）
- **⬇ 匯出備份／⬆ 匯入檔案**：名單是存在「這台電腦的這個瀏覽器」，換到教室電腦時，用備份檔帶過去就好

## 公平性怎麼做到的

- 抽人與分組都用瀏覽器內建的**密碼學等級亂數**（`crypto.getRandomValues`），並避開取餘數造成的機率偏差，每個人被抽到的機率完全相同
- 轉盤／拉霸是**先公平決定結果，再讓動畫停在那個人**，所以轉盤上格子的排列順序不影響機率
- 分組的「平均分配」採**分層發牌**：同類的人（例如同性別）洗牌後輪流發到各組，各組人數與各類人數最多只差 1；選「性別＋系級」時，會再交換同性別的兩人，讓各組系級也盡量平均（性別人數完全不變）

## 使用方式

1. 開啟 <https://jsai99.github.io/JAPP/class-wheel/>，或下載專案後雙擊本資料夾的 `index.html`（建議 Chrome／Edge）
2. 第一次開啟會有一個「範例班級」可以先玩玩看
3. 按「📋 名單管理」→「＋ 新增班級」→ 貼上名單 →「💾 儲存」
4. 上課時按 **F** 全螢幕、按 **空白鍵** 開始

### 快捷鍵

| 按鍵 | 功能 |
|---|---|
| `空白鍵` | 開始抽／開始分組（結果畫面時＝保留） |
| `R` | 結果畫面：移除抽中的人 |
| `Enter`／`Esc` | 結果畫面：保留在名單中 |
| `F` | 全螢幕 |
| `M` | 音效開／關 |

## 技術說明

- 純 HTML／CSS／JavaScript，零相依套件、零建置流程
- 音效全部用 **Web Audio API 即時合成**（鐘聲、小鼓、號角和弦），沒有任何音檔，也就沒有版權問題，離線也能用
- 資料存在瀏覽器的 `localStorage`（鍵名 `japp.classWheel.v1`）

## 參考過的工具

[Wheel of Names](https://wheelofnames.com/)、[Picker Wheel 分組](https://pickerwheel.com/tools/random-team-generator/)、[Spinwheelify](https://spinwheelify.com/zh-TW)。借鏡了它們的「抽中後移除」「轉動時間長短」「依性別或標籤平均分組」「每組抽代表」等設計，再針對課堂投影與名單隱私重新設計。
